# Fase 3 · Paso 11 · Editor profesional por bloques

## Antes de subir a GitHub
1. Abre Supabase > SQL Editor.
2. Ejecuta `09-editor-profesional-por-bloques.sql`.
3. Confirma que existan las tablas `lesson_blocks`, `block_responses` y `course_versions`.
4. Después reemplaza los archivos del repositorio con este paquete.
5. Limpia la caché desde `limpiar-cache.html`.

## Cómo usarlo
1. Entra como administrador o instructor.
2. Abre **Administrar**.
3. En una tarjeta de curso pulsa **Editor por bloques**.
4. Selecciona una lección en la columna izquierda.
5. Agrega bloques desde la columna derecha.
6. Los cambios se guardan automáticamente.
7. Usa **Guardar versión** antes de cambios importantes.
8. Usa **Vista alumno** para revisar el resultado.

## Incluido
- Texto, video, imagen, PDF, audio, actividad y separador.
- Autoguardado por bloque.
- Reordenar bloques.
- Eliminar bloques.
- Versiones manuales y restauración.
- Vista del alumno conectada a los bloques.
- Respuestas privadas en actividades.
- Publicar curso desde el editor.
