# Aula Compás V5.3 — cursos responsive

Esta versión corrige la visualización de los cursos en teléfonos.

## Cambios

- La imagen del curso destacado aparece arriba.
- El título, descripción, botones y progreso aparecen en un bloque independiente.
- Las tarjetas del carrusel separan la fotografía de la información.
- La pantalla “Mis cursos” utiliza tarjetas verticales limpias.
- La portada interior de cada curso también evita textos superpuestos.
- Se reparan textos que puedan aparecer como `CompÃ¡s` o `direcciÃ³n`.
- Se actualiza la versión del Service Worker para retirar la caché anterior.

## Publicación en GitHub

1. Descomprime este ZIP.
2. Sube todos los archivos a la raíz del repositorio de Aula Compás.
3. Reemplaza los archivos existentes.
4. Confirma el cambio con el mensaje:

   `Corrige cursos responsive y codificación`

5. Abre `limpiar-cache.html` desde la URL pública.
6. Presiona el botón para limpiar la versión anterior.
7. Regresa al aula y actualiza.
