
# Paso 15 · Centro de accesos y productos

1. Ejecuta `13-centro-accesos-productos.sql` en Supabase SQL Editor.
2. Reemplaza los archivos del repositorio con este paquete.
3. Limpia la caché desde `limpiar-cache.html`.
4. Entra como administrador.
5. Abre: Administrar → espacio de trabajo → Accesos y ventas.
6. Crea un producto, selecciona cursos/libros y concédelo a un alumno.

Este paso prepara las referencias y la tabla de órdenes para Mercado Pago.
El webhook automático se implementa en el siguiente paso.
